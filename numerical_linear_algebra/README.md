# Numerical Linear Algebra

This directory contains implementations and experiments in numerical
linear algebra, focusing on matrix factorizations, orthogonalization,
eigenvalue problems, and numerical methods for solving polynomial
equations.

## Projects

### LU Factorization
Implementation of LU factorization using the Crout algorithm, with
forward and backward substitution for solving linear systems.

### LDLᵀ Factorization
Implementation of the LDLᵀ factorization for symmetric matrices.

### QR Algorithm
Implementation of QR factorization using Gram-Schmidt orthogonalization
and Householder reflections, together with the QR algorithm for
eigenvalue computation.

### Weighted Gram-Schmidt
Implementation of the Gram-Schmidt process under a weighted inner product
using symbolic computation.

### Polynomial Roots
Collection of analytical and numerical methods for finding polynomial
roots, including the quadratic formula, fixed-point iteration, and the
secant method.

### Polynomial Analyzer
A modular polynomial analysis tool combining symbolic computation,
numerical root finding, differentiation, extrema, monotonicity,
concavity, integration, and visualization.

## Goals

The goal of these projects is to study how concepts from linear algebra
and numerical analysis can be translated into computational algorithms,
while exploring their numerical behavior and limitations.
