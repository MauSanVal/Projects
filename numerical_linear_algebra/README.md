# Numerical Linear Algebra

This directory contains implementations and experiments related to
numerical linear algebra.

The projects focus on the computational aspects of linear algebra,
with emphasis on numerical algorithms, matrix factorizations, and
eigenvalue problems.

## Projects

### QR Algorithm
Implementation of the QR algorithm for computing eigenvalues of a matrix.

- QR factorization
- Eigenvalue computation
- Numerical experiments

## Goals

The main goal of these projects is to study how concepts from linear
algebra can be translated into computational algorithms, while
examining their numerical behavior and limitations.
